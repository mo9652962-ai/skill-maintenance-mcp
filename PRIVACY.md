# Privacy Policy for skill-maintenance-mcp

**Last Updated:** October 2026

`skill-maintenance-mcp` is an open-source, local-first Model Context Protocol (MCP) server for automating AI agent skill maintenance, backups, corruption scanning, and decision logging.

## 1. Local Processing & Zero External Telemetry
- All skill directory parsing, file backups, hash validations, and health inspections execute **100% locally** on the user's filesystem.
- No skills, code, prompt workflows, or telemetry metrics are transmitted to any remote servers.

## 2. Zero Network Footprint
- `skill-maintenance-mcp` performs zero outbound network calls. It contains no analytics beacons, tracking pixels, or remote telemetry SDKs.

## 3. Data Ownership
- The user retains 100% custody and control of all skills, backup archives, and decision logs created on disk.

## 4. Contact
For questions or concerns, please open an issue at [mo9652962-ai/skill-maintenance-mcp](https://github.com/mo9652962-ai/skill-maintenance-mcp).
